# stocktake (モバイルファースト メーラー風 在庫・購入日記録)

アイテム名と購入日だけに特化した、**スマートフォン / モバイルファーストUIの在庫・購入日記録 Web アプリケーション** です。

データはすべてブラウザの **LocalStorage** に保存されます。

---

## 🌟 主な特徴

* **アイテムに関わる項目は「アイテム名」と「購入日」のみ**:
  * 余計なプロパティを排除した超シンプル仕様。
* **購入日の古い順に自動ソート（固定）**:
  * 直近の購入日から最も時間が経っている（買い足しが必要な可能性が高い）アイテムが先頭に並びます。
* **スマホ片手でサクサク使える設計**:
  * **受信トレイ一覧 (Inbox View)**:
    * 大きなタッチ領域のアイテム行（タップで詳細画面へ遷移）
    * チェックボックスによる複数選択
    * 右下に片手親指で届く **フローティング追加ボタン（FAB: ＋）**
    * アイテム選択時に画面下部から出現する **ボトム一括アクションバー（📝購入日記録、🗓️Googleカレンダー連携、🗑️削除）**
      * **Googleカレンダー連携**: カレンダーを開く、または選択アイテムの次回購入予定日（終日予定、アイテム名と最終購入日リスト入り）を追加可能
  * **詳細・購入日履歴画面 (Detail View)**:
    * 左上「←」戻るボタンで一覧へスムーズに戻る
    * **購入日履歴タイムライン**: 過去のすべての購入日をカード一覧表示（個別削除に対応）
    * 最下部に「🗑️ このアイテムを削除」
  * **ボトムシート (Bottom Sheet)**:
    * 新規アイテム追加や日付指定一括購入は、画面下部からスッとせり上がるモバイルネイティブなボトムシートを採用。
* **SPA（Single Page Application）構成**:
  * **Vite + Preact + TypeScript (TSX)** による高速かつ軽量なモダンSPA構成。
  * **URLルーティング・ブラウザ履歴対応**:
    * 一覧画面（`#/`）と詳細画面（`#/items/:id`）がそれぞれ独立したURLを持ち、ブラウザの「戻る」「進む」ナビゲーションに完全連動。
    * 詳細画面のURLを直接ブックマークやリロードしても、そのアイテムの詳細画面を直接開くことが可能。
* **レスポンシブ対応（スマホ・タブレット・PC）**:
  * **モバイル (< 640px)**: 画面いっぱいにフィットするモバイル最適化ビュー。片手操作しやすい親指ファースト設計。
  * **タブレット・PC (>= 640px)**: 最大幅860px〜1024pxの洗練されたカード型アプリコンテナとして中央表示。
    * モーダルはボトムシートから画面中央のダイアログにシームレスに変化。
    * 各ボタン・行にホバーエフェクトを追加し、マウスクリックでも快適に操作可能。
    * 一括アクションバーやカレンダーポップオーバーも中央コンテナに合わせて心地よく配置。
  * **Tailwind CSS 導入**: Tailwind CSS を採用し、モダンなレスポンシブスタイリングを実現。

## 🚀 開発・起動方法

Node.js 環境で以下のコマンドを実行します：

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (http://localhost:3000)
npm run dev

# 型チェック (TypeScript)
npm run typecheck

# 静的解析 (ESLint)
npm run lint

# コード整形 (Prettier)
npm run format

# プロダクションビルド
npm run build

# ビルドプレビュー
npm run preview
```
