# Zaiko (モバイルファースト メーラー風 在庫・購入日記録)

アイテム名と購入日だけに特化した、**スマートフォン / モバイルファーストUIの在庫・購入日記録 Web アプリケーション** です。

データはすべてブラウザの **LocalStorage** に保存されます。

---

## 🌟 モバイルファーストUIの特徴

* **スマホ片手でサクサク使える設計**:
  * **受信トレイ一覧 (Inbox View)**:
    * 大きなタッチ領域のアイテム行（タップで詳細画面へ遷移）
    * チェックボックスによる複数選択
    * 右下に片手親指で届く **フローティング追加ボタン（FAB: ＋ アイテム追加）**
    * アイテム選択時に画面下部から出現する **ボトム一括アクションバー（⚡今日購入、📅日付指定、🗑️削除）**
  * **詳細・購入日履歴画面 (Detail View)**:
    * 左上「←」戻るボタンで一覧へスムーズに戻る
    * 親指で一瞬でタップできる幅広の **「⚡ 今日購入を記録する」** ボタン
    * **購入日履歴タイムライン**: 過去のすべての購入日をカード一覧表示（個別削除、過去日追加に対応）
    * 最下部に「🗑️ このアイテムを削除」
  * **ボトムシート (Bottom Sheet)**:
    * 新規アイテム追加や日付指定一括購入は、画面下部からスッとせり上がるモバイルネイティブなボトムシートを採用。
* **アイテムに関わる項目は「アイテム名」と「購入日」のみ**:
  * カテゴリ・数量・価格・メモなどの余計なプロパティを排除した超シンプル仕様。
* **PC・タブレット表示**:
  * デスクトップで開いた場合でも、中央にスマートフォンのビューポート（最大幅520px）として美しく表示されます。
