# Zaiko (ミニマル メーラー風 在庫・購入日記録)

アイテム名と購入日だけに特化した、**メーラー風ミニマルUIの在庫・購入日記録 Web アプリケーション** です。

データはすべてブラウザの **LocalStorage** に保存されます。

---

## 🌟 特徴

* **アイテムに関わる項目は「アイテム名」と「購入日」のみ**
  * カテゴリ・数量・価格・メモなどの余計な項目をすべて排除し、シンプルに管理できます。
* **メーラー風のミニマル 2 ペイン UI**
  * **左ペイン (受信トレイ風)**:
    * チェックボックスによる複数選択
    * アイテム名、最新の購入日（「今日」「昨日」「3日前」などの相対表記）、購入回数
    * 検索バー & ソート切り替え
    * 上部一括アクションバー: **[⚡ 今日購入]**、**[📅 日付指定]**、**[🗑️ 削除]**
  * **右ペイン (閲覧画面風)**:
    * 選択したアイテム名と最新購入日
    * **[⚡ 今日購入を記録]** ワンクリックボタン
    * **購入日履歴リスト**: 過去のすべての購入日を一覧表示（個別削除・過去の日付追加に対応）
* **アイテムの追加**
  * アイテム名を入力するだけで即座に追加可能（必要に応じて初回の購入日も指定可能）
* **複数アイテムの一括購入記録**
  * チェックを入れて上部の「⚡ 今日購入」を押すだけで、今日の日付をまとめて記録できます（カレンダーで過去の日付を選ぶことも可能）。

---

## 🚀 動かし方

ブラウザで [`index.html`](./index.html) を開くだけですぐに動作します（ビルド・サーバー不要）。
